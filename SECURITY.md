# Security policy

## Supported versions

Only the latest release receives fixes. Please update before reporting.

## Reporting a vulnerability

Please do not open a public issue. Report privately through
[GitHub's vulnerability reporting](https://github.com/Common-Fool/VO_Media/security/advisories/new)
(Security → Report a vulnerability).

Include the VO Media version, your OS, what you did, what happened and, if you can,
the steps to reproduce it.

VO Media runs a local web server for its window, launches your video player,
and renames and deletes files in the folders you open, so reports about
any of these are especially welcome.
