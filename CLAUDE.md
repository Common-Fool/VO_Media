# CLAUDE.md

# VO Media

Быстрый просмотрщик фото и видео для огромной библиотеки на NAS (SMB): локальный кеш SQLite + миниатюры, листание фото и видео
в одном окне, сортировка по имени/дате/размеру/длительности, раскладка папок с числом файлов и размером.
Python 3.8+, только стандартная библиотека; `pywebview` необязателен; ffmpeg не нужен. Первая версия — только просмотр.

Устройство, схема БД, API, клавиши — `docs/CONTRACT.md` (договор модулей; при изменении интерфейсов — править его первым).
Родственный проект и образец решений — VSPO: `..\Steam_View\pairview.py` и его `CLAUDE.md`.

## Договорённости с владельцем

- Общаться по-русски, коротко, технически плотно. Интерфейс, сообщения, журнал, `--help` — на английском; комментарии в коде — по-русски.
- **Без прямого разрешения владельца не запускать** приложение, `py_compile`, проверки JS, сборку. Проверка — чтением кода и ревью.
- Не пытаться воспроизводить Windows, SMB, WebView2 в песочнице: это проверяет владелец.
- Среда владельца: Windows 10/11, RTX 5080, библиотека на Synology по SMB (больше 1 млн файлов; мелкие запросы по сети дорогие).

## Планы (просил владелец, не сделано)

- Открыть папку / показать файл в проводнике (как `show_in_explorer()` в VSPO: `explorer /select,`, macOS `open -R`, Linux `xdg-open`).
- Контекстное меню по правому клику на плитке и в просмотрщике: открыть, открыть во внешнем плеере (выбор плеера как в VSPO: `play()`,
  `list_players()`), показать в проводнике, переименовать, копировать (файл в буфер обмена для вставки в проводнике и/или путь),
  удалить — **обычное удаление** (владелец: без `_to_delete` и Ctrl+Z, «для остального есть корзина» — корзина Synology `#recycle`
  на общей папке / корзина Windows на локальных дисках). С подтверждением своим диалогом `ask()`. Это отменяет «только просмотр» v1.
- Переключатель автовоспроизведения видео в просмотрщике (вкл — видео стартует при переходе на него, выкл — как сейчас, по Space);
  хранить в настройках, показать в панели просмотрщика и в меню.
- GIF наравне с видео (объём согласован с владельцем): попадает в фильтр Videos, на плитке значок ▶ и длительность
  (сумма задержек кадров из заголовка GIF, `meta.py`), миниатюра — первый кадр. В просмотрщике GIF показывается `<img>` и просто
  крутится: без паузы, перемотки, шкалы и таймлайна.
- Слайдшоу в просмотрщике: полупрозрачная кнопка в левом верхнем углу; при наведении на неё появляется шкала скорости (вид как
  у шкалы громкости) — интервал от 5 с до 0,5 с. Фото переключаются по таймеру; видео — не по таймеру, а по окончании
  воспроизведения (видео при этом запускается само). Переходит и между папками, как ←/→ (уточнить у владельца).
- Переключатель «следующее видео по окончании текущего» — только в пределах одной папки (в конце папки останавливается).
- Переключатель «зациклить видео» — текущее видео крутится по кругу (`loop`). Вместе с ним «следующее по окончании» не срабатывает.
- Все три переключателя и автовоспроизведение — в панели просмотрщика, состояние в настройках.
- Превью «с условиями» (листы кадров как в VSPO для тысяч видео) — обсудить отдельно.
- Другие форматы видео (mkv, ts) — перепаковка ffmpeg на лету, по желанию.
- Сборка на GitHub Actions, релизы, самообновление (как в VSPO).

## Грабли (из VSPO, не повторять)

1. `SO_REUSEADDR` в Windows → два экземпляра на одном порту: только `SO_EXCLUSIVEADDRUSE`.
2. `localStorage` для настроек → теряются при смене порта: настройки на сервере.
3. Системные `confirm()`/`alert()` в окне pywebview не гарантированы — свои диалоги.
4. Тело POST читать всегда (keep-alive).
5. Обходить NAS в обработчике запроса нельзя (кроме одной папки в `refresh_dir`): по SMB это секунды-минуты.
6. `canvas.toBlob` / `OffscreenCanvas.convertToBlob` для миниатюр → Chromium откладывает кодирование на простой потока, замерено ~0,9 с
   на штуку. Только `toDataURL` (~20 мс), см. `canvasBlob()` в `app.js`.
7. Пути длиннее 260 знаков в Windows без префикса `\\?\` дают `FileNotFoundError` — кеш принял бы папку за удалённую. Все пути к NAS — через `Library._abs()` (`long_path()`).

## Сборка exe (только с разрешения владельца)

```
python -m PyInstaller --noconfirm --onefile --noconsole --name "VO Media" --add-data "vomedia/web;vomedia/web" --collect-all webview --collect-all pythonnet --collect-all clr_loader --icon assets/vomedia.ico vomedia.py
```

Результат — `dist\VO Media.exe` (~23 МБ). Страница берётся из `sys._MEIPASS/vomedia/web` (`server.web_dir()`).
Иконка — `assets/vomedia.ico` (рисует `assets/make_icon.py`, нужен Pillow; во вкладке страницы — такой же SVG в `<link rel="icon">`).
Workflow GitHub Actions пока нет — сборка вручную.
